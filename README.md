# Vehicle Maintenance & Projects

Centralized repository for tracking maintenance, repairs, projects, and documentation for boats, RVs, and cars.

## Organization

### [Boats/](Boats/)
Evinrude outboards, marine engines, and watercraft maintenance
- Engine service records and diagnostics
- Parts lists and technical manuals
- Maintenance schedules
- Repair projects

### [RVs/](RVs/)
Motorhome and travel trailer maintenance
- Chassis and mechanical work
- Appliance servicing
- Electrical systems
- Storage and winterization procedures

### [Cars/](Cars/)
Automotive maintenance and repairs
- Service records
- Repair documentation
- Parts specifications
- Troubleshooting guides

### [Shared/](Shared/)
Cross-vehicle resources
- Tool inventories
- Supplier contacts
- Reference documents
- General maintenance procedures

## Getting Started

Each vehicle category contains:
- `README.md` - Overview and quick reference
- `MAINTENANCE_LOG.md` - Service history and upcoming maintenance
- Specific folders for projects, manuals, and parts documentation

## Usage

- Create a new issue or folder for each significant maintenance task or project
- Document work completed with dates and details
- Keep manuals and technical specifications organized by vehicle/system
- Link related work across vehicle types when applicable
