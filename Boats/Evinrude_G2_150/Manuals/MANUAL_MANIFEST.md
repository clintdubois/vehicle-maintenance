## Storage Strategy

Due to file size constraints and git repository best practices:
- PDF manuals are stored in the source location: `Camping/Boat/`
- This manifest documents their existence and location
- Markdown documentation is version-controlled in this repository
- HTML archives are included for reference when PDFs are unavailable

## Accessing Manuals

To locate the PDFs referenced here:
1. Navigate to `Camping/Boat/` in the workspace
2. Look for files matching the names listed above
3. Or download fresh copies from:
   - operatorsguides.brp.com (official BRP/Evinrude operator guides)
   - manualslib.com (community-hosted service manuals)
